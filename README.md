# Deep Sea Creatures 🌊

Deep Sea Creatures is a relaxing ocean-themed collection game developed with Unity.

Explore the deep sea, discover unique marine creatures, upgrade your fishing equipment, complete daily missions, and build your own underwater collection.

---

## 🎮 Features

- Rare sea creature collection system
- Fishing progression gameplay
- Daily missions and rewards
- Lucky spin system
- Luxury-inspired ocean UI
- Seasonal gameplay changes
- Mobile-friendly controls

---

## 📱 Platform

- Android
- Built with Unity Engine

---

## 🛠️ Technologies Used

- Unity
- C#
- Universal Render Pipeline (URP)
